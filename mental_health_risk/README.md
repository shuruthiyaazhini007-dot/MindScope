# MindScope — Mental Health Text Classification Prototype

A student project that classifies a text entry into **Normal, Anxiety, Depression, or Suicidal** using TF-IDF and a trained machine-learning model. The Streamlit interface includes optional reflection fields, word-weight explanations, session-based trends, support information, and model evaluation results.

> **Important:** This is an educational prototype, not a clinical tool. It cannot diagnose a person or reliably determine their mental state from text alone. Predictions can be wrong; prioritize human support and professional care.

## What's included

- `app.py` — redesigned Streamlit website with sidebar navigation and seven pages:
  - **Dashboard** — overview cards and quick navigation
  - **Analyze Text** — text input, optional self-reported mood/stress/sleep/context, class probabilities, word-weight highlighting
  - **Reflection Prompts** — optional prompts and downloadable text notes
  - **Trend Tracker** — session-based chart, table, summary, CSV download and clear-history action
  - **Support Library** — general support ideas and helpline details
  - **Model Insights** — training metrics, per-class report, confusion matrix and key settings
  - **About & Privacy** — limitations and privacy notes
- `utils.py` — existing shared text-cleaning, safety phrase, score and explanation functions
- `train.py` — existing dataset cleaning, model comparison and artifact generation
- `data/dataset.csv` — included training dataset
- `models/` — trained model, vectorizer, metrics and confusion matrix (generated by `train.py`)
- `requirements.txt` — Python dependencies
- `run.bat` / `run.sh` — launch helpers

The added mood, stress, sleep and context fields are **self-reported context only**; they do not affect the model prediction. Trend scores are model-generated estimates, not evidence of clinical change. Session history is not written to a database by this project, but hosting, logs, shared devices and browser configuration may still affect privacy. Avoid entering identifying details.

## Run in VS Code (Windows)

1. Extract the ZIP file.
2. In VS Code, choose **File → Open Folder** and open the `mental_health_risk` folder.
3. Open the terminal (**Ctrl + `**).
4. Run these commands one at a time:

```powershell
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python train.py
streamlit run app.py
```

Open the local URL printed by Streamlit, usually `http://localhost:8501`.

### macOS / Linux

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python train.py
streamlit run app.py
```

`python train.py` regenerates `models/model.joblib`, `models/vectorizer.joblib`, `models/metrics.json`, and `models/confusion_matrix.png`. The deployed model selection and core prediction logic remain in the original training/utilities code.

## Dataset format

The CSV should have `text` and `status` columns. Supported labels are `Normal`, `Anxiety`, `Depression`, and `Suicidal`. If you change column names, update `TEXT_COL` and `LABEL_COL` in `utils.py`, then retrain.

## Configuration

Review `utils.py` for the probability threshold, low-confidence warning, safety phrase patterns, support tips and helpline information. Confirm local contact information before relying on it.
